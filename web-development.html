Lesson 1: What is HTML?

HTML stands for HyperText Markup Language. It is used to create the structure of webpages.

HTML uses tags to tell the browser what different parts of a webpage are.

Example

<h1>My Website</h1>

<p>Welcome to my website.</p>

The <h1> tag creates a heading, while the <p> tag creates a paragraph.

Lesson 2: What is CSS?

CSS stands for Cascading Style Sheets.

CSS controls how a webpage looks. You can use CSS to change colors, fonts, spacing, backgrounds and more.

Example

color: blue;

font-size: 20px;

HTML gives a webpage its structure, while CSS helps make that webpage look attractive.
